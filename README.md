## What I Actually Work With (and Why It Matters)

### Java — The Core

I've been writing production Java since 1.8 and have hands-on experience migrating enterprise applications from Java 8 to Java 21. That means dealing with module system changes, deprecated API replacements, library compatibility issues, and making sure nothing breaks in production during the transition. Not a version bump — a proper migration with regression testing and zero-downtime deployments.

### Data Layer

**MongoDB 8.x** — Worked through a major version migration, handling schema validation changes, aggregation pipeline updates, and index strategy adjustments that come with it.

**MySQL** — Used in personal projects and earlier work. Comfortable with query optimization, indexing strategies, and relational modeling.

**Redis** — Caching layer for high-throughput services. Used for session management, rate limiting, and reducing database load where latency matters.

### Messaging & Event-Driven Architecture

**Apache Kafka** — Event streaming for decoupled microservices. Dealt with consumer group rebalancing, partition strategies, and exactly-once semantics in practice.

**MQ (Message Queues)** — Asynchronous processing for tasks that don't need immediate responses. Helps keep APIs fast while heavy work happens in the background.

### AI & Prompt Engineering

**Amazon Q AI Agent** — Built and integrated AI agents with optimized prompt practices. This isn't just calling an API — it's structuring prompts for consistent, reliable outputs in production workflows where hallucinations cost real money.

### DevOps & Deployment

**Jenkins** — CI/CD pipelines for automated builds, tests, and deployments. Not just clicking "build now" — writing pipeline scripts, managing environments, and handling rollback strategies.

**ELK Stack (Elasticsearch, Logstash, Kibana)** — Centralized logging for distributed systems. When something breaks at 2 AM, you need searchable, structured logs — not grep on a server.

**Health Checks** — Implemented application health endpoints for monitoring and alerting. If a service is degrading, we know before users do.

### Security & Compliance

**Enterprise Security Layers** — Applied authentication, authorization, input validation, and API security at the application level. Not theoretical — actual implementation in production systems handling real user data.

**Log Masking** — Sensitive data (PII, tokens, credentials) never hits log files in plain text. Built masking utilities that strip or obfuscate sensitive fields before they reach ELK or any log sink.

### Testing & Quality

**JUnit** — Unit and integration testing as part of the development workflow. Not writing tests after the fact — tests are part of the definition of done.

**JMeter** — API load testing to find breaking points before users do. Identifying bottlenecks, connection pool limits, and memory leaks under sustained load.

### Documentation & Process

**Swagger/OpenAPI** — API documentation that stays in sync with code. Consumers don't guess — they read a contract.

**JIRA** — Sprint planning, story breakdown, and tracking. Enterprise-scale project management, not just a to-do list.

### Automation & Engineering Practices

I actively look for manual, repetitive work and automate it. If someone is doing it by hand more than twice, it should be scripted or built into the pipeline.

Design principles and coding practices aren't buzzwords in my work — they're how I structure enterprise applications. SOLID, clean architecture, separation of concerns, proper error handling, meaningful abstractions. Code that other engineers can read, extend, and maintain six months later without a walkthrough.

### Personal Projects

**React + JavaScript** — Frontend work lives in my personal projects. Building UIs, understanding the full request lifecycle from browser to database and back.
